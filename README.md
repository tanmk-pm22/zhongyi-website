# 福田药行 - 中医诊所管理系统

一个现代化的中医诊所网站，包含患者注册和QR码管理系统。

## 🌟 功能特色

### 已完成功能
- ✅ 诊所介绍网站
- ✅ 医师团队展示（杨源森医师、周祥音医师）
- ✅ 服务项目介绍（内科、妇科、儿科、男科、针灸、推拿）
- ✅ 在线预约系统（含推拿特殊规则）
- ✅ **患者注册系统**
- ✅ **QR码自动生成**
- ✅ **患者病历查询**
- ✅ **SQLite 数据库** - 患者数据永久保存
- ✅ 联系方式和营业时间

### 患者注册系统
- 收集完整的患者资料（姓名、身份证/护照、地址、联系方式）
- 记录紧急联系人
- 记录病史、过敏史、用药史
- 自动生成唯一患者编号
- 生成专属QR码供患者保存
- 支持QR码下载和打印

### 病历查询系统
- 扫描患者QR码快速调取病历
- 输入患者编号查询
- 显示完整患者资料和病史
- 特别标注药物过敏信息

## 📋 系统要求

- Node.js 16.x 或更高版本
- 现代浏览器（Chrome、Firefox、Safari、Edge）

## 🚀 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 打开浏览器
访问 http://localhost:3000

## 💾 数据存储

### SQLite 数据库（已实现）✅
**患者数据永久保存**，服务器重启不会丢失！

- **数据库文件**：`data/patients.db`
- **自动初始化**：首次运行自动创建数据表
- **数据备份**：定期备份数据库文件即可
- **详细说明**：查看 [数据库说明.md](./数据库说明.md)

### 数据备份建议
**重要**：请定期备份 `data/patients.db` 文件
- 复制到U盘或云盘
- 建议每天备份一次
- 查看数据库文档了解详细备份方法

### 升级到云数据库（可选）
如需多人访问或更大容量，可升级到：
- Vercel Postgres（推荐）
- MongoDB Atlas
- PlanetScale

## 🛠️ 技术栈

- **前端框架**: Next.js 14 + React 18
- **样式**: Tailwind CSS
- **UI组件**: Lucide React Icons
- **QR码**: qrcode 库
- **语言**: TypeScript
